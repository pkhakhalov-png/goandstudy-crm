# SITE.md — Go & Study CRM

## Purpose
CRM-система для образовательного агентства Go & Study. Управление клиентами, платежами, расходами и аналитикой продаж.

## Pages

### /login — Авторизация
Форма входа по email/паролю. Минималистичная, по центру экрана.

### /admin — Главная (Dashboard)
KPI-карточки с ключевыми метриками. Графики выручки по месяцам. Список должников.

### /admin/clients — Клиенты
Таблица всех клиентов с фильтрами по статусу, стране, продажнику. Кнопка создания нового клиента.

### /admin/payments — Платежи
Таблица платежей с фильтрами. Возможность отметить оплату, добавить комментарий.

### /admin/expenses — Расходы
Расходы по кураторам и продажникам. Группировка по месяцу создания клиента. Фиксированные расходы.

### /admin/sales — Аналитика продажников
Сводка по каждому продажнику: клиенты, суммы, зарплата по месяцам.

### /admin/settings — Настройки
Управление продажниками, кураторами, фиксированными расходами.

### /sales — Кабинет продажника
Список своих клиентов. Создание нового клиента.
