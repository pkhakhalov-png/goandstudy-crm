# SEO-блок Go&Study — полный отчёт

_Дата: 2026-09-09 · Домен: goandstudy.com · Окно данных Search Console: 12.05–06.09.2026 (~117 дней)_

---

## 1. Резюме

В CRM встроен полноценный SEO-движок: он сам обходит сайт, тянет данные из Google Search
Console, раскладывает страницы по темам (кластерам), находит проблемы и точки роста, и
помогает планировать новые статьи так, чтобы они не конкурировали с уже существующими.

**Что показали данные за ~4 месяца:**
- Сайт получает **11 070 кликов** при **845 743 показах** из поиска Google.
- Средний CTR ≈ **1,3 %** — это **низко**; при показах почти в миллион даже частичный подъём
  кликабельности даёт кратный прирост трафика без единой новой страницы.
- Найдено **555 конкретных проблем/возможностей**, из них львиная доля — «дешёвые» победы:
  страницы уже ранжируются, надо лишь дожать.

**Три главных вывода:**
1. **CTR-провал на высокочастотных информационных запросах.** Страницы стоят в топ-10 по
   запросам с тысячами показов, но их почти не кликают (см. §5.1) — проблема заголовков/сниппетов.
2. **Каннибализация «сервис vs блог».** По коммерческим запросам конкурируют посадочная и
   блоговая страницы, размывая позиции (см. §5.3).
3. **Технический долг по разметке.** 82 страницы без schema.org — теряются rich-результаты (§5.4).

## 2. Что умеет модуль (архитектура)

Изолированная схема `seo` в базе (основную CRM не трогает). Очередь задач + фоновый воркер.

| Слой | Функция |
|---|---|
| **Инвентарь** | обход sitemap, парсинг каждой страницы (title, H1, meta, canonical, ссылки, JSON-LD), граф внутренних ссылок |
| **Search Console** | OAuth-подключение, импорт кликов / показов / позиций по страницам и запросам |
| **Эмбеддинги** | векторное представление каждой страницы (Voyage `voyage-3`, 1024 измерения) |
| **Кластеры** | тематическая группировка страниц (spherical k-means по смыслу) |
| **Находки** | автоматический поиск проблем и возможностей (11 видов), каждая привязана к кластеру |
| **Статьи** | планирование новых материалов с учётом кластера: анти-дубль + подсказки перелинковки |

Интерфейс: **`/admin/seo`** — вкладки Обзор / Страницы / Кластеры / Статьи / Находки / Эксперт.

### 5.1. CTR-провал — самый быстрый выигрыш 🟢
Страницы в топ-10, но кликабельность в разы ниже нормы для позиции. Это чистая работа с
заголовком (title) и сниппетом (meta description) — контент менять не надо.

| Показов | Позиция | Факт CTR / норма | Запрос | Страница |
|---:|---:|---|---|---|
| 11 643 | 7,2 | 0,2 % / 3 % | «phd» | /blog/chto-takoe-**pdh** ⚠️ опечатка в URL |
| 9 597 | 6,9 | 0,4 % / 3 % | «gpa» | /blog/chto-takoe-gpa |
| 9 270 | 6,5 | 0,3 % / 4 % | «gpa это» | /blog/chto-takoe-gpa |
| 6 968 | 5,0 | 0,1 % / 5 % | «toefl стоимость» | /blog/kak-sdavat-toefl |
| 5 430 | 4,9 | 0 % / 5 % | «toefl цена» | /blog/kak-sdavat-toefl |
| 3 734 | 8,1 | 0,2 % / 2,5 % | «toefl» | /blog/kak-sdavat-toefl |

**Действие:** переписать title/description этих 5–6 страниц под интент запросов. Потенциал —
сотни дополнительных кликов/мес при уже имеющихся позициях. Отдельно: у страницы про PhD
**опечатка в URL** (`pdh` вместо `phd`) — исправить + 301-редирект.

### 5.2. Striking-distance — дожать до 1-й страницы 🟢
Страницы на позициях 11–20 с заметным спросом. Небольшое усиление (контент, перелинковка,
ссылки) выводит на 1-ю страницу, где кликают в разы больше.

| Показов | Позиция | Запрос | Страница |
|---:|---:|---|---|
| 358 | 19 | «обучение за границей» | /blog/ucheba-za-granitsey |
| 340 | 12,9 | «поступление в италию» | /blog/kak-poehat-uchitsya-v-italiyu |
| 252 | 10,6 | «грант на учебу в китае» | /grant-v-kitaj |
| 248 | 11 | «языковые школы в сша» | /yazykovye-kursy-v-ssha |
| 242 | 11,5 | «курсы английского языка в сша» | /yazykovye-kursy-v-ssha |
| 197 | 18,4 | «магистратура в сша» | /magistratura-v-ssha |

(всего 200 таких — полный список во вкладке «Находки».)

### 5.3. Каннибализация — сервис vs блог 🟢
Один запрос тянут несколько страниц, конкурируя между собой и размывая позиции. Классика —
коммерческая посадочная против блоговой статьи.

- **«языковые курсы в сша»** → /yazykovye-kursy-v-ssha (поз.5, **102 клика**) vs /blog/kak-ostatsya… (поз.2,7, 1 клик) — блог перехватывает позицию, но не конвертит.
- **«помощь в поступлении за границу»** → главная (поз.3, 72 клика) vs /polnoe_soprovozhdenie (поз.34, 2 клика).
- **«поступление в италию»** → /postupit-v-italiyu vs /blog/kak-poehat-uchitsya-v-italiyu (обе в топ-15).
- **«магистратура в австрии»** → /magistratura-v-avstrii vs /…na-anglijskom-yazyke.

**Действие:** для каждой пары выбрать «главную» страницу под запрос, вторую — переориентировать
на смежный интент и поставить внутреннюю ссылку на главную. 18 таких конфликтов.

### 5.4. Технический долг 🟡
- **82 страницы без schema.org** — теряются rich-результаты в выдаче. Концентрация: языковые
  школы (24/24), кейсы (12), Италия (6). *Модуль может сгенерировать готовый JSON-LD автоматически.*
- **54 title** вне диапазона 20–65 символов, **28** внутренних ссылок в никуда, **13** страниц-сирот,
  **3 битые ссылки** (чинить в первую очередь), **нет /llms.txt** (ориентир для AI-поиска).

## 6. Дорожная карта

### Готово (в проде)
Инвентарь, Search Console, эмбеддинги, кластеры, все виды находок, планировщик статей
с анти-каннибализацией, порт технических чеклистов (claude-seo). Интерфейс `/admin/seo`.

### Ближайшие шаги (по данным этого отчёта)
1. **CTR-спринт** — переписать title/description для 6 страниц из §5.1 (+ фикс URL `pdh→phd`). Самый быстрый ROI.
2. **Разметка** — сгенерировать schema.org для 82 страниц (модуль умеет автономно).
3. **Каннибализация** — развести 18 пар «сервис/блог» (§5.3).
4. **Striking-distance** — усилить топ-20 страниц из §5.2.

### Требует доступа (не блокирует аналитику)
- **WordPress Bridge** — авто-публикация правок/статей прямо из модуля (нужен mu-plugin + app-пароль).
- **/llms.txt** — разместить на хостинге сайта.
- **GSC в Vercel env** — чтобы воркер обновлял Search Console по расписанию (переменные уже добавлены).
