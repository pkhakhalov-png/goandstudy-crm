## Правила, о которых договорились

1. **Действующую SEO-систему не трогаем.** Как пишутся статьи, какие проверки,
   какой стандарт — настроено и работает. Строим поверх.
2. **Миграции не применяю сам.** Кладу SQL в `docs/sql/`, копирую в буфер
   через `pbcopy`, Павел выполняет в Supabase SQL Editor.
3. **Каждую находку проверять на живых данных** до того, как объявлять сделанной.
4. Учёт расходов **никогда не останавливает** конвейер статей — только пишет.
