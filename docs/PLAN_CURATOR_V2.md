### Что проверено на боевой базе

Контрольные до и после всех операций совпадают: клиентов 75, кураторов 12, записей подборок 140, заданий SEO 1841.

Ключом кабинета v2 через тот же API, которым пользуется приложение:

```
✓ чтение клиентов              прошло
✓ ИЗМЕНЕНИЕ имени клиента      отказано (403)
✓ СОЗДАНИЕ клиента             отказано (403)
✓ УДАЛЕНИЕ клиента             отказано (403)
✓ чтение платежей              отказано (403)
✓ чтение расходов              отказано (403)
✓ изменение подборки вузов     отказано (403)
✓ изменение этапа клиента      отказано (403)
✓ анонимом: чтение care        отказано (401, permission denied for schema care)
✓ анонимом: запись в care      отказано (401)
```

После открытия схемы прогнан дымовой тест всех контуров: клиенты, платежи, очередь SEO, контент — 200. Действующая CRM работает.
