# SEO-модуль Go&Study — статус

_Обновлено: 2026-09-09_

Единый SEO-движок в CRM: инвентарь сайта → Search Console → тематические кластеры →
находки → создание статей. Живёт в изолированной схеме `seo` (не трогает основную БД CRM).
Интерфейс: **`/admin/seo`** (вкладки Обзор / Страницы / Кластеры / Статьи / Находки / Эксперт).

### 3. WP Bridge (M4) — авто-публикация в WordPress 🔒 нужен доступ
Код готов, но **инертен без доступа к сайту**. Чтобы включить:
- положить `wp-bridge/goandstudy-seo-bridge.php` в `wp-content/mu-plugins/`;
- в `wp-config.php`: `define('GS_SEO_BRIDGE_SECRET', '<секрет>')`;
- в Vercel env: `WP_BASE_URL`, `WP_BRIDGE_SECRET`.
Без этого «Статьи» предлагают темы и перелинковку, но публикуешь вручную.

### 4. `/llms.txt` 🔒 нужен доступ к хостингу сайта
Файл-ориентир для AI-ассистентов. Разместить на `goandstudy.com` (это WordPress, не CRM).

### 5. Автопилот по расписанию
Настройки есть (`autopilot_enabled`, дневные лимиты). Реальную авто-работу с контентом
(генерация → публикация) держит п.3 (WP Bridge).

## Как оперировать модулем

**Из интерфейса** (`/admin/seo`): кнопки «Инвентарь», «GSC-находки», «Технический аудит»,
«Пересчитать находки», «Пересчитать кластеры», форма создания статьи.

**Локальные скрипты против прод-БД** (для прогонов без ожидания крона):
| скрипт | что делает |
|---|---|
| `npx tsx scripts/seo-run-inventory.ts` | краул sitemap → страницы/ссылки |
| `npx tsx scripts/seo-recrawl.ts` | перекраул всех страниц (обновляет has_schema) |
| `npx tsx scripts/seo-embed.ts` | эмбеддинги |
| `npx tsx scripts/seo-cluster.ts [k]` | кластеризация (k пусто = авто) |
| `npx tsx scripts/seo-gsc.ts` | импорт Search Console |
| `npx tsx scripts/seo-gsc-findings.ts` | GSC-находки |
| `npx tsx scripts/seo-technical.ts` | технический аудит |
| `npx tsx scripts/seo-night-run.ts start` | инвентарные находки + проверка ссылок |

**Доступы, которые уже есть:** Supabase (ручные миграции через SQL Editor, ref `pxtwaxhmygnssyyowrgr`),
Voyage-эмбеддинги, Google Search Console.

**Доступы, которых не хватает:** WordPress (mu-plugin + app-пароль) — только для авто-публикации и llms.txt.
