# Независимая проверка SEO-блока

Проверено 11.09.2026 по фактической реализации, а не по отчётам предыдущих
сессий. Каждая строка — либо подтверждена вызовом, либо помечена как непроверенная.

## Как читать статусы

- **работает** — проверено вызовом или следом в базе;
- **частично** — работает, но не на всех путях;
- **есть код, не подтверждено** — реализация существует, срабатывание не наблюдалось;
- **отсутствует** — не реализовано;
- **заблокировано** — упирается во внешнюю зависимость.

## 3. Техническое SEO

Проверено на живой статье `/blog/kak-poluchit-grant-obuchenie-kitae/`:

```
HTTP 200 · canonical на себя · title и description на месте · один H1
JSON-LD есть · карточка на /blog/ есть · адрес в sitemap.xml есть
картинок 1, отдаётся 200 · X-Robots-Tag не закрывает
```

**Статьи из файлов темы в sitemap попадают** — проверено: 160 адресов в
`sitemap.xml`, наша статья среди них. Опасение, что стандартный механизм
WordPress их не увидит, не подтвердилось.

**Несогласованность формы адреса подтверждена, но не исправлена.** Внутренние
ссылки ведут на адрес без слэша, который отдаёт 301 на адрес со слэшем;
canonical и sitemap используют форму со слэшем. Google в индексе держит обе
формы у разных страниц. Массовую правку не делал: это 165 ссылок на живом
сайте, требует отдельного согласования. Скрипт готов —
`server-agent/fix-trailing-slash.sh`.

страницам — Search Console скрывает часть запросов. Это не ошибка импорта.
