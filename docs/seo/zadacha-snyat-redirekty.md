# Задача: снять 301-е редиректы с одиннадцати страниц

Выполнять на сервере сайта (WordPress, Timeweb Cloud, Москва).

## Зачем

С конца августа сайт потерял почти половину поискового трафика: 885 кликов в
неделю → 473. Позиции при этом не упали — 7,2 против 7,1 в июле. Значит сайт не
наказан, а перестал отвечать на конкретные запросы.

Причина — 50 страниц, склеенных постоянными редиректами в общие. Из 930
потерянных кликов 504 приходится на них.

Склейка не сработала и по замыслу. Показы частично перешли на общие страницы, а
клики нет:

| | показы авг → сен | клики авг → сен | CTR |
|---|---|---|---|
| `/granty-v-ssha` (убрана) | 5 196 → 500 | 160 → 6 | была 3,1 % |
| `/postupit-v-ssha` (цель) | 359 → 1 952 | 2 → 4 | 0,2 % |

Конкретная страница под конкретный запрос собирала 3 % кликов. Общая страница,
показанная по тому же запросу, — 0,2 %, в пятнадцать раз хуже. Человек ищет
«магистратура в Китае», попадает на «поступить в Китай» и уходит.

## Что сделать

Вернуть одиннадцать адресов: снять 301 и отдавать по ним страницу со своим
содержимым, отвечающим запросу.

Порядок важен — он по потерянным кликам. Эти одиннадцать дают 93 % потери.

## Чего НЕ трогать

`/contacts`, `/faq`, `/page86753416.html`, `/postupit-v-avstriyu-old` — честно
устаревшие адреса, редирект им к лицу. Не снимать.

И не выключать плагин редиректов целиком: там есть нужные правила. Снимать
правила поштучно, по списку выше.

## Порядок работы

### 1. Найти, где заданы редиректы

Заголовок ответа говорит, что это WordPress, а не nginx:

```
curl -sI https://goandstudy.com/granty-v-ssha | grep -iE 'HTTP|location|x-redirect'
→ HTTP/1.1 301 Moved Permanently
→ X-Redirect-By: WordPress
→ Location: https://goandstudy.com/postupit-v-ssha/
```

Значит источник один из трёх, проверить по очереди:

- плагин редиректов (Redirection, Rank Math → Redirections, Yoast Premium);
- правило в теме или в `functions.php` (поискать `wp_redirect`, `wp_safe_redirect`);
- сама страница в WordPress удалена или в корзине, и WP уводит на родителя.

Третий случай отличается тем, что правила редиректа нигде нет. Проверить:

```
wp post list --post_type=page --post_status=any --field=post_name | grep -E 'granty-v-ssha|magistratura-v-kitae|kolledzhi-v-ssha'
```

### 2. Снять редирект и проверить, что страница есть

Страница должна отдавать **200 и своё содержимое**, а не пустой шаблон. Если
содержимое удалено — восстановить из корзины (`wp post list --post_status=trash`)
или из резервной копии. Если его нет нигде, страницу надо написать заново: пустая
страница с кодом 200 хуже редиректа.

Содержимое должно отвечать именно своему запросу. `/magistratura-v-kitae` — про
магистратуру в Китае: программы, сроки подачи, язык, стоимость. Не копия общей
страницы про поступление в Китай, иначе Google склеит их сам.

### 3. Проверить результат

```
for u in granty-v-ssha yazykovye-kursy-v-ssha srednee-obrazovanie-v-avstrii \
         magistratura-v-kitae kolledzhi-v-ssha magistratura-v-avstrii \
         grant-v-kitaj universitety-avstrii-na-anglijskom \
         bakalavriat-v-kitae-na-anglijskom bakalavriat-v-kitae magistratura-v-dubae; do
  printf '%-40s ' "/$u"
  curl -s -o /dev/null -w '%{http_code}\n' "https://goandstudy.com/$u"
done
```

Все одиннадцать должны отдавать `200`. Если где-то остался `301` — правило не
снято или кешируется, проверить кеш WordPress и nginx.

### 4. Сказать поисковикам

После того как все одиннадцать отдают 200:

- добавить их в `sitemap.xml`, если их оттуда убрали;
- отправить на переобход через Search Console (URL Inspection → Request indexing)
  и через IndexNow для Яндекса.

## Чего ждать

Снятый 301 не возвращает трафик в тот же день: Google должен заново обойти
страницу и вернуть её в индекс. Это две-шесть недель, и прежние позиции
возвращаются не всегда. Чем дольше стоит редирект, тем хуже шансы — поэтому
делать стоит сейчас.

Возврат этих одиннадцати — это примерно +470 кликов за три недели по августовским
меркам, то есть примерно половина всего, что сайт потерял.

## Что сообщить обратно

1. Где нашлись редиректы — плагин, тема или удалённые страницы.
2. Какие из одиннадцати страниц сохранили содержимое, какие пришлось
   восстанавливать, каких нет совсем.
3. Вывод проверки из пункта 3 — все ли отдают 200.
